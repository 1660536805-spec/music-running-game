# 06 演示视频脚本（≤3 分钟）

> 表单要求：录屏需含**语音讲解或字幕**，清晰演示产品思路与核心功能；时长 ≤3 分钟，大小 ≤500M，无水印杂音，原创合规。
> 本脚本按 **180 秒**编排，一条主线：**「换歌即换关」**；节奏从"是什么 → 怎么玩 → 为什么不一样 → 现场证明"层层递进。
> 建议：**全程录屏 + 配音**，字幕同期显示关键词即可。

---

## 一、分镜表（180 秒）

| 时间 | 画面 / 操作 | 解说词（配音） | 屏幕字幕 |
|---|---|---|---|
| **0:00–0:15** | 标题卡（黑底或主视觉）→ 淡入主枢纽 | "大多数音游停在'类型层'——把歌换成任意一首，玩法其实没变。我们做了另一件事。" | 声浪星球 · Soundwave Planet ／ 换歌即换关 |
| **0:15–0:40** | 主枢纽界面停留 2 秒 → 点「⚡ 超频长阶」→ 角色起跑 | "《声浪星球》，一款 3D 低多边形跑酷音游。它把一首歌的结构——前奏、主歌、副歌、高潮、尾声——直接翻译成跑道的地形与机关。" | 段落是地形 · 节拍是障碍 · 旋律是航线 |
| **0:40–1:05** | 进入副歌：镜头贴身、速度拉满、成批机关出现 | "注意这一拍——**副歌开闸**。速度、镜头、机关的密度，全部由段落结构决定。你听出歌在涨，就知道接下来要发生什么。" | 副歌开闸 Chorus Gate |
| **1:05–1:25** | 操作者**故意撞向**一个"像障碍"的物体 → 穿过、无扣分 | "这个看着像障碍的东西，是**误导体**。撞上去不扣分——它专门筛一种人：靠眼睛反应的人吃亏，跟着音乐呼吸的人受益。" | 误导体：撞了不扣分 |
| **1:25–1:45** | 双闸门处**什么都不按**静静穿过 → 随即长按蓄能 → 高潮 Drop 俯冲 | "双闸门的正解，是**什么都不按**——'不操作'也是有效输入。预副歌长按蓄能，高潮 Drop 强制一次决定性俯冲。跑道上只有升、降、同调，时间，是唯一的决策维度。" | 时间 = 唯一的决策维度 |
| **1:45–2:10** | 返回 → 点「选择歌曲」→ 换 **song2** → 起跑（关卡构成明显不同） | "现在重点：我没有改一行代码，只是换了一首歌。段落结构变了，机制组合就变了。这就是**换歌即换关**。" | 换歌即换关 |
| **2:10–2:40** | 打开「上传你的歌」→ 选本地 MP3 → 分析进度条 → 直接起跑 | "更狠的在这里：**任意一首歌**。上传后本地实时分析，不联网、不依赖提前做好的谱面，当场生成段落、障碍与航线，直接开跑。" | 上传任意歌 · 本地实时生成关卡 |
| **2:40–3:00** | 曲终 → 结算面板（S 评级/连击/准确率）→ 定格标题 | "整首歌跑完，自动结算。判定、计分、镜头、结算——换歌时一行都没改。把流行乐从'听'的位置，挪到'决定怎么玩'的位置。" | 用音乐，探索更远的世界 |

## 二、录制清单（开拍前逐项确认）

1. **画面**：1920×1080 全屏录屏；隐藏浏览器书签栏 / 关闭系统通知与微信弹窗；鼠标光标可见（便于评委跟随操作）。
2. **音频**：游戏音量为主要声源，配音占主导（游戏声建议压到 30% 左右，避免盖住讲解）；**务必无杂音、无水印**。
3. **前置动作**：进入页面前**先点击画面一次**解锁浏览器音频（手势策略），再开始录制。
4. **素材准备**：提前备好 1 首 1–1.5 分钟的本地歌（规整流行/电子），供 2:10 上传环节使用——**曲风规整**能保证段落识别最准。
5. **时长控制**：若配音偏慢，优先压缩 0:15–0:40 的介绍与 2:40 的收尾，**保底**保住 1:45（换歌）和 2:10（上传）两个高光。
6. **导出**：MP4 / H.264，≤500M（180 秒 1080p 通常 <200M，安全）。

## 三、字幕规范

- 关键词级字幕即可：只显示每段右侧「屏幕字幕」列的内容，随解说出现、停留 2–3 秒。
- 字体：PingFang SC / 微软雅黑，白色 + 半透明描边；位置统一屏幕下方居中。
- 机制名（副歌开闸 / 误导体 / 换歌即换关 / 上传任意歌）**建议加亮色强调**，帮助评委抓住记忆点。

## 四、翻车兜底

| 情况 | 处理 |
|---|---|
| 上传环节识别不准（自由节奏/古典曲） | 当场说明"分析器对自由节奏会有误判，这正是我们诚实的边界"，随即回退到 **内置 song2** 继续演示。 |
| 上传分析耗时偏长 | 用 1–1.5 分钟短曲；进度条可见时边等边讲机制，不冷场。 |
| 浏览器拦截 / 无文件权限 | 直接回退内置曲，口播一句"上传能力同样已跑通，回放时可现场复现"。 |
| 音频未解锁 / 无声 | 重新点击画面一次；若仍无声，用字幕兜底（本脚本已含完整字幕）。 |

## 五、拍摄优先级（万一只能录 1 分钟）

**必须留住的镜头**（按重要性）：① 换歌即换关（1:45）→ ② 上传任意歌现场生成（2:10）→ ③ 误导体撞了不扣分（1:05）。
这三个镜头，就能把"机制层而非类型层"讲清楚。
