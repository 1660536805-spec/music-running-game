# 声浪星球 · 答辩脚本 & Demo 时间线

> 面向评委的现场执行脚本。**一条主线**：*"我们做的不是第 N 个音游，是把流行乐从'听'的位置，挪到'决定怎么玩'的位置。"*
> 全程围绕四根支柱：**换歌即换关 · 时间即唯一决策维度 · 只奖励不惩罚 · 判定口径跨歌一致**。

---

## 0. 电梯陈述（30 秒，开口即用）

> "大家熟悉的大多数音游，停在'**类型层**'——你把歌换成任意一首，玩法其实没变，只是音符落得不一样。
> 我们做了另一件事：把这首歌的**结构**——前奏、主歌、预副歌、副歌、桥段、高潮、尾声——直接翻译成**跑道的地形和机关**。
> 于是有了那句判据：**换歌，即换关**。
> 接下来 8 分钟，我会**换一首歌给你们看**——你会看到，同一套引擎，跑出了完全不同的关卡。"

## 2. 四根支柱 ↔ Demo 动线 映射

> 这是本脚本的骨架：**每一根支柱，都有一个"肉眼可见"的 Demo 证据**，不靠 PPT。

| 支柱 | 一句话定义 | Demo 证据（时间点） |
|---|---|---|
| **① 换歌即换关** | 段落结构决定机制组合，而非仅换音符落点 | 5:10 换 song2（双预烘焙对照）+ **6:10 现场上传任意歌** |
| **② 时间即唯一决策维度** | 只有"升/降/长按"，且"不操作"是有效输入；无侧向选择 | 3:00 双闸门"不操作=正解" |
| **③ 只奖励不惩罚** | 误导体碰了不扣分，漏拍不断连击归零式惩罚；错只体现在"少赚" | 2:20 撞误导体不加分也不扣分 |
| **④ 判定口径跨歌一致** | 判定窗口按 BPM 归一，换歌不换手感口径 | 7:20 两首歌共用同一结算/判定，均"跟得上就命中" |

## 3. ★ P5 现场上传环节（杀手锏，务必演练）

**为什么放压轴**：这是唯一能**当场证明"不是提前录好的"**的环节——评委任意点一首歌，我们当场生成关卡。

### 动线
1. 枢纽 → 点「**选择歌曲**」→ 浮层内点「**上传你的歌**」。
2. 选中一个**本地 MP3 / WAV / M4A**（建议提前备好 3 首：规整电子 / 流行 / 说唱，覆盖不同难度）。
3. 出现**分析进度条**（本地实时分析，不上传服务器）。
4. 分析完成 → **直接起跑** → 展示：段落划分、障碍节奏、旋律航线、副歌开闸、高潮 Drop。

### 话术锚点
> "整个过程在**本地**完成：解码 → 分析 BPM/段落/旋律 → 生成谱面 → 进入游戏。**没有上传、没有出网、没有提前准备的谱面**。这就是我们说的——**任意一首歌，就是一张新关卡**。"

### 兜底（若现场上传翻车）
| 情况 | 处理 |
|---|---|
| 选了**自由节奏/古典/极端复杂**的歌，段落判得不准 | "分析器对自由节奏会有误判——这正是我们诚实的边界。**主演示限定流行/电子**；复杂曲目我们提供'手动标注段落'的高级入口兜底。" |
| 分析耗时偏长 | 提前选一首**时长 1–1.5 分钟**的歌；进度条可见，边等边讲机制。 |
| 浏览器拦截 / 无文件权限 | 立即回退到**内置 song2**（6:10 双预烘焙对照），口头补一句"上传能力同样已跑通，回放时可现场复现"。 |
| 音量 / 音频未解锁 | 先点击画面一次再操作（浏览器手势策略）。 |

## 4. 评委 Q&A 速答卡

> 高频质疑的**一句话应答**（详版见产品设计文档 §8.2）。

| 质疑 | 速答 |
|---|---|
| "这不就是 Beat Saber / 世界计划换皮？" | 类型层 vs **机制层**：他们换歌不换规则，我们**由段落结构决定机制组合**——刚现场换的两首歌玩法不同，就是证据。 |
| "版权怎么办？（赛题方向 A 的致命伤）" | 内置曲**只用可授权素材**：合成曲 + **CC-BY 并署名**（Kevin MacLeod / incompetech.com）；用户上传歌**仅本地分析、不上传**（红线 R6）。技术链路与素材权利**解耦**——我们是"授权范式的接口提案"。 |
| "单赛道太单调，玩两遍就腻。" | 变化来自**歌**，不来自赛道。换歌即换关 + 难度档位 + 段落机制轮转；内容量来自歌库。 |
| "自动生成会不会破坏你们的视觉复刻？" | 自动生成**严格限定在 causeway 新场景**（有独立基线），不碰四场景几何；新视觉走独立随机流。 |
| "分析和判定不准，歌一复杂就崩。" | 主演示限定节拍规整曲风；提供手动校准；判定口径**按 BPM 归一**（P4），跨歌一致。 |
| "不就是自嗨？" | 误导体直接证明用户价值：**凭视觉反应的人吃亏，跟着音乐的人受益**——一首歌就能让评委亲身体验差异。 |
